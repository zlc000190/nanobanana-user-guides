# Nano Banana primary-source checklist

[Nano Banana](https://nanobanana.page/) is the primary project entry point for this independent browser-based AI image workflow note. The automated HTTPS availability check on 2026-07-24 did not return a response, so current product availability and capabilities must be confirmed from primary documentation before use.

## Evidence to collect

- current usage-rights terms
- current retention policy
- the saved prompt and reference image

## Two controlled questions

- a licensed reference image
- a typography-heavy prompt

For every material statement, record the source URL, publisher, publication or update date, access date, and the exact claim supported. A search snippet, copied directory description, or unsourced social post is a discovery lead, not final evidence.

## Acceptance gate

Do not approve the workflow when a material claim lacks a current primary source. Label assumptions, jurisdiction limits, and unresolved contradictions explicitly. This note is not official product documentation or professional advice.
