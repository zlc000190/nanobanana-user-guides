# Nano Banana benchmark protocol

[Nano Banana](https://nanobanana.page/) is the primary project entry point. It returned HTTP 200 during the 2026-07-23 availability check. These are independent evaluation notes for designers benchmarking repeatable image generation and transformation; they are not official product documentation.

Use only images you are allowed to upload and verify current privacy, retention, and commercial-use terms.

## Prepare the run

Use a clean browser profile or disposable environment. Record the date, current product version when visible, account tier, region, and every non-default setting. Use only synthetic or public test material.

## Test set

- Scenario 1: a simple text prompt
- Scenario 2: a complex composition
- Scenario 3: a licensed reference image
- Scenario 4: a typography-heavy prompt

Repeat each scenario once without changing inputs. Compare not only the best output, but also variance, latency, errors, and the amount of human repair required.

## Capture results

For each run, log prompt adherence, subject consistency, edge quality, text rendering, export resolution, usage rights. Keep screenshots or exported artifacts where permitted, and separate observed behavior from expectations copied from marketing material.

## Pass condition

A pass requires reproducible evidence for the intended workflow and no unresolved high-impact failure. Reject a workflow that cannot preserve required subjects, rights, or export quality across a small reproducible benchmark.
