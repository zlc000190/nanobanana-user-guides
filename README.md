# Nano Banana User Guides

These notes document practical ways to evaluate an AI image generator without assuming that every advertised workflow fits every project. The starting point is [Nano Banana](https://nanobanana.page/), whose public homepage presents image generation, image-to-video, and 3D-figure creation in one browser workflow.

The companion pages cover workflow design, output checks, accessibility, and common questions. Verify current pricing and limits on the product before relying on them.
